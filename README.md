# 영어 섬 여행

아이패드 홈 화면 웹앱으로 동작하는 만 4세용 영어 글자 소리 놀이 게임. 한글 섬 여행 엔진을 다시 써서 만들었고, 외부 라이브러리 없이 HTML, CSS, JS, SVG로 되어 있다.

- 주소: https://conan-ccc.github.io/english-island/
- 발음 확인(보호자용): https://conan-ccc.github.io/english-island/tools/voice-check.html

배우는 것: 1~6섬은 영어 소문자 26개의 소리(파닉스)와 그림 단어, 7섬은 소리 합치기(c-a-t → cat), 8섬은 가족·인사 단어(mom, dad, baby, grandma, grandpa, hello). 안내는 한국어, 배우는 소리와 단어는 영어 목소리로 나온다.

## 아이패드 설치

1. 사파리로 위 주소를 연다.
2. 공유 버튼 → "홈 화면에 추가"를 누른다.
3. 홈 화면의 "영어 섬" 아이콘으로 실행한다. (사파리 탭에서만 쓰면 7일 동안 안 열 때 기록이 지워질 수 있다.)
4. 이름은 묻지 않는다. 선물상자를 세 번 누르면 영어 섬 친구가 태어난다.
5. 보호자 공간: 화면 오른쪽 위 모서리를 2초 길게 누른 뒤 덧셈 문제를 푼다. 소리·글자 이름·대문자 표시 설정, 진행 표, 백업 코드(EI1:)가 있다.
6. 글자 소리가 어색하면 발음 확인 페이지에서 글자마다 다른 소리나 "단어로 대신"을 고른다.

한글 섬 여행과 같은 주소(conan-ccc.github.io) 아래에 있지만 저장 기록과 오프라인 캐시는 따로 쓴다. 영어 섬에서 "처음부터 다시"를 해도 한글 섬 기록은 지워지지 않는다.
